# INVISIO E-learning prototype

A static, clickable prototype built from the six-wireframe flow:

1. Login
2. Homepage
3. Course selection
4. Introduction to NATO overview
5. Scrollable course reader
6. Quiz and completion screen

## Add to GitHub
Upload `index.html`, `styles.css`, and `script.js` to the root of the repository and commit the changes.

## Vercel
Import the GitHub repository. Vercel can deploy this as a static site with no build command.

## Add the real NATO content
The current reader contains three placeholder pages. If the NATO material is a PDF, add it to the repository as `nato-course.pdf`. The reader can then be switched to an embedded PDF, or its pages can be converted into HTML/images for tighter visual control.

## Note
This is a visual prototype. Login and progress are stored only in the browser session and are not connected to a database.
